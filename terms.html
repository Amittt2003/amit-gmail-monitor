Terms of use

Personal use

Amit Gmail Monitor is a personal automation operated by Amit for his own mailbox. It is not offered as a public email service, and this website does not offer account registration.

Purpose and permissions

The monitor provides optional Telegram alerts about selected new email. It uses Gmail metadata access only. The operator controls authorization, monitoring rules, and whether monitoring is enabled. Data practices are described in the privacy policy.

Availability and accuracy

Alerts depend on the Raspberry Pi, network availability, Google authorization and APIs, Telegram delivery, and filtering rules. Checks are scheduled every 15 minutes; delivery and classification are not guaranteed. The operator should continue checking Gmail for messages requiring timely attention.

Stopping use

The operator can disable monitoring and revoke Google access at any time. Previously delivered Telegram messages can be deleted using Telegram's controls.
