Privacy policy

Amit Gmail Monitor is operated by Amit exclusively for personal monitoring of his own Gmail mailbox.

Google data access

The application requests only https://www.googleapis.com/auth/gmail.metadata. It reads message identifiers, history identifiers, labels, and headers including sender, subject, date, and automation-related headers. This permission does not provide access to email bodies or attachments or permit sending, editing, deleting, archiving, or marking email as read. The permission covers mailbox metadata; the monitor's code filters alerts to new inbox arrivals.

How data is used

Metadata is used to identify new messages matching personal or important email rules, create notifications, and prevent duplicate alerts. Google user data is not used for advertising, sold, or used to train AI models. Email classification currently runs as local rules without a model call.

Storage and retention

OAuth credentials are stored on the operator's Raspberry Pi in a file restricted to its owner. Local monitoring state stores synchronization identifiers, a list of processed message identifiers, and check timestamps. State is updated during polling and remains on the Raspberry Pi until the operator clears it. The monitor does not maintain a local archive of email bodies or attachments. The operator may delete credentials and monitoring state to remove locally stored data.

Telegram notifications and service providers

Selected message metadata (sender, subject, alert reason, and Gmail message link) is transmitted to Telegram to deliver an alert to the operator's private chat. Alerts remain in Telegram until deleted under Telegram's controls and policies. Google processes Gmail API access; Telegram processes notification delivery. GitHub hosts this public informational website; no OAuth credentials or mailbox data are published on it.

Control and deletion

The operator can pause monitoring, revoke the application's access in Google Account settings under connections to third-party apps and services, delete local credentials and state, and delete Telegram alerts. Revoking access stops future Gmail access but does not delete alerts already sent to Telegram.

Limited use

Amit Gmail Monitor's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
