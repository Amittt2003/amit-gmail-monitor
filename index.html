Important email.
A quiet alert.

A personal assistant running on Amit's Raspberry Pi checks for new important or personal email every 15 minutes and sends a notification to Amit's private Telegram chat.

Read-only, limited access

The monitor uses the Gmail API to read email headers and labels: sender, subject, date, and metadata used to identify automated messages. It cannot read message bodies or attachments, send email, delete messages, archive messages, or mark messages as read.

Google access is used only to identify relevant new messages and avoid duplicate alerts. Notifications contain the sender, subject, reason for the alert, and a link to the message in Gmail.

For one person's own mailbox

This is a private, personal-use application operated by Amit. There is no public sign-up, advertising, or sale of email data.
